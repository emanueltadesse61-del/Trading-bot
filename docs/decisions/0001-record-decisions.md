# 0001 — Record technical decisions here

Date: 2026-10-16. Status: Accepted.

## Context
Two AI models and the owner work through handoffs. Decisions made in chat get lost or contradicted.

## Decision
Every accepted technical decision, spec amendment, or resolved disagreement gets a numbered file in this folder: context, options considered, the evidence that decided it, and the decision. Spec amendments must be dated before the results they affect are seen.

## Consequences
Chat summaries link to these records rather than acting as competing specifications.
